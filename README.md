# Dungeon Raid 网页版

**▶ 在线游玩：<https://coolking70.github.io/DungeonRaid/>**

经典连线消除 Roguelike《Dungeon Raid》（Android 1.2.11 版）的 TypeScript 重写版，可以直接在浏览器里玩，手机和电脑都支持。目标是**规则忠实**：伤害公式、敌人能力、随机数算法以及调用顺序，都依据对原版程序的逆向分析还原。同一个种子，每次都会打出完全相同的对局。

## 功能

- **连线**：拖动连接 3 个以上相邻的同类格子，剑可以和骷髅连在一起。拖线时实时预览本次伤害和会击杀的敌人。
- **敌人**：普通敌人加 32 种特殊敌人。冰冻、点燃、偷金、巫妖与命匣、倒计时等能力全部生效；敌人数值实时显示，点按或长按可查看详情。
- **成长**：升级二选一、商店购买装备、强化装备、42 个技能、领取奖杯来升级或解锁职业。
- **模式与职业**：Classic、Dungeon Sprint（100 回合冲刺）、Pretzel Hero（交叉连线）三种模式；4 种难度；10 个职业，可配置种族、优点、缺点和替换技能。
- **界面**：原版风格的局内 HUD、折叠菜单、动画和音效。结算期间点按屏幕可立即跳过动画。
- **局外**：主菜单、教程、高分榜（6 页）、成就、统计、设置。
- **其他**：中英双语切换；自动存档，刷新页面后可以继续；长期档案（职业等级、高分、成就）保存在浏览器本地。

若页面资源疑似未更新，可在「设置 → 清除缓存（保留存档）」重新获取游戏资源并刷新。当前对局、职业进度、奖杯计数和设置都会保留；下载失败可重试。该功能仅刷新本游戏资源，不清除浏览器的全部站点数据。

「设置 → 辅助显示」可分别关闭顶部信息栏、连线伤害汇总、统计和属性中的奖杯击杀计数。三个开关默认开启、独立保存；关闭仅影响显示，不改变游戏规则。

路线图与进度见 [docs/PLAN.md](docs/PLAN.md)。

## 本地开发

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev          # 开发服务器，地址 http://localhost:5310，加 ?debug 进入调试台
npm run check        # 类型检查、全部测试和数据校验
npx vite build       # 构建发布版本，输出到 dist/
```

当前本地及发布版本默认使用 `art/native/` 原版美术：棋盘与状态、菜单/职业/种族/技能图标、400个装备图标、启动图和应用图标。英文与数字使用原版位图字体，中文及原版缺失字形保留 Fusion Pixel 回退。加 `?art=redrawn` 可对照此前整套重绘美术（缺失格子变体仍使用原版格位）；教程示例实时使用当前资源绘制。来源与范围见 [art/native/README.md](art/native/README.md)。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `src/core/` | 纯规则引擎，没有 DOM 依赖。入口是 `step(state, action) → { state, events }` |
| `src/audio/` | 音效播放器：优先播放 `audio/original/` 中的原版音效，加载失败时回退到程序合成 |
| `ui/` | 网页界面：320×480 逻辑画布、屏幕栈、动画时间线 |
| `test/` | Vitest 测试，包括规格行为用例、整局确定性模拟、存读档往返 |
| `docs/spec/` | 从原版程序还原的规则与界面规格，每条结论都附带证据 |
| `docs/tasks/` | 各阶段的任务卡和执行报告 |
| `data/` | 规则与界面数据表（枚举、装备、职业、特殊敌人、布局、音效、i18n 文本） |
| `art/` | `native/` 原版默认美术；另保留棋盘、界面、装备重绘图集供对照 |
| `audio/original/` | 原版音效 |
| `fonts/` | Fusion Pixel 12px 像素字体的子集（SIL OFL 1.1，许可证文本随附） |
