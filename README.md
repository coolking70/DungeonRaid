# Dungeon Raid 网页移植版（非官方）

**▶ 在线游玩：<https://coolking70.github.io/DungeonRaid/>**

这是经典连线消除 Roguelike《Dungeon Raid》（Android 1.2.11 版）的规则移植，用 TypeScript 重新实现，可以在浏览器里玩。目标是**规则忠实**：伤害公式、敌人能力、随机数算法和调用顺序都依据原版程序的逆向分析还原，同一个种子每次都会得到完全相同的对局。

> 本项目是非官方的粉丝移植，与原作者 Firedrake Games 没有任何关联，仅供学习和娱乐。仓库和网页**不包含任何原版美术或音效**，棋盘图块是另行创作的原创美术。

## 现在能玩什么

- 拖动连接 3 个以上相邻的同类格子，剑可以和骷髅连在一起。拖线时会实时预览这一下能击杀哪些敌人。
- 普通敌人和 32 种特殊敌人：倒计时、冰冻、点燃、偷金、巫妖与命匣等能力全部生效。
- 成长系统：
  - 升级时二选一；
  - 商店购买装备；
  - 装备强化；
  - 42 个技能；
  - 领取奖杯升级或解锁职业。
- 10 个职业，4 种难度，Classic 和 Sprint（100 回合冲刺）两种模式。

开发中：Pretzel 模式、计分与高分榜、成就、存档 / 读档、职业配置界面、原版风格的界面与音效。路线图见 [docs/PLAN.md](docs/PLAN.md)。

当前界面是**调试台**样式：完整规则加上基础画面，原版风格的界面复原安排在后续阶段。

## 本地开发

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev          # 开发服务器，地址 http://localhost:5310
npx vitest run       # 规则引擎测试
npx vite build --mode pages && node tools/check-dist.mjs   # 公开版本构建与素材检查
```

- 公开版本（`--mode pages`）使用 `art/` 下的原创图集。
- 本地开发模式会尝试从 gitignore 的 `reverse/` 目录读取原版贴图，这部分只用于个人对照，不随仓库分发。没有这个目录时，可以用 `npx vite --mode pages` 预览原创美术版。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `src/core/` | 纯规则引擎。没有 DOM 依赖；入口是 `step(state, action) → { state, events }` |
| `test/` | Vitest 测试，覆盖规格中的行为用例和整局确定性模拟 |
| `docs/spec/` | 从原版程序还原的规则规格，每条结论都附有证据 |
| `docs/tasks/` | 各阶段的任务卡和执行报告 |
| `data/` | 规则数据表（枚举、装备、职业、特殊敌人等） |
| `ui/` | 网页界面 |
| `art/` | 原创美术图集及其来源清单 |
