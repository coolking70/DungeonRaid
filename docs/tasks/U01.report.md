## 原始证据抽查（回到伪C复核5条）

1. **投影与留边**：重读`Game::SetupRenderer @0x26470`。`glOrthof(0,0x3f800000,0x3fc00000,0,0xc1200000,0x41200000)`即(0,1,1.5,0,-10,10)；视口按0.6666667判断，窄屏height=int(width/0.6666667)，宽屏width=int(height*0.6666667)，差值×0.5再截断。和10章/JSON一致。
2. **棋盘位置**：重读`Game::CalculateTilePositions @0x25f64`：中心`(column+.5)*cell+.003125`、`(row+.5)*cell+.246875+challengeOffset`，两层循环止于6；`Game::Start @0x260ac`的cell=`0x3e29999a=.165625`，乘320得53，左上1/79；挑战偏移`0x3c800000=.015625`为5。和10章/JSON一致。
3. **金币填充**：重读`Interface::UpdateGoldBar @0x4a1dc`：`value/0x14`、`value%0x14`；宽`.05*n*320=16n`、满列高`0x3e433333=.190625→61`，余列高`.009375*r*320=3r`；bottom`1.4875→476`、left`.015625→5`，零值移到world(200,200)。和资源公式一致，未误作连续横条。
4. **Token速度与终止**：重读`Token::Process @0x65200`：u先加a*dt，再按u≤1/大于1两段积分；比较的是v*dt或u*v*dt与移动前距离，不是混合向量长度。伪C的Clamp参数缺失，额外核对Thumb`0x552ca–0x552f8`得到ratio和`.2/1`；11章记录了此差别，没有虚构固定飞行时长。
5. **高分分页**：重读`ScoreScreen::Process @0x5dba8`：0..5钳制、缓存交换、`.00625→2px`吸附阈值；进一步核对Thumb`0x4dc86–0x4dc9a`的`.4`速度权重与`0x4dcd0–0x4dce0`的`.3`位置权重。结论是逐帧插值，并非0.3秒补间。

额外交叉核对修正了HUD Menu在上、Stats在下；游戏菜单的Clock/Dimming/Smooth顺序；折叠菜单是X平移；13个伪C丢参声音调用均补了Thumb证据。所有规格/JSON中的明确`Class::Function @address`引用与本地反编译函数头核对，无名称/地址不一致。

## 对U02的建议

以320×480逻辑空间组织SceneStack/BoardView/HudView/Overlay，输入先减视口偏移再归一化；resize只重建视口/画布，不重新开局。保留原生层级与屏幕专用Render分支，但实现结构是建议而非反编译出的类继承。

每个动画独立elapsed和完成条件，分别支持积分、固定时长补间、逐帧吸附，不能统一塞进固定时长Tween。维护规则快照与显示快照；事件进入有序表现队列，播放阶段可延迟显示，不能改变引擎EffectConsumed/菜单提交的规则顺序。暂停/恢复冻结表现时钟，不重放整轮声音或重复结算。

现有引擎已消费token/particle/flare等COSMETIC随机数但未输出结果；UI不可再推进规则RNG。后续如需保真，可按P3只增不改约束暴露已抽样值并加测试；临时原创视觉扰动与声音变体可用独立UI/audio seed，但必须标记近似。声音事件候选必须结合资源类型、敌人/技能分支、菜单选项与展示阶段，不能按事件名无条件播声。

U02可先实现坐标、分层、时间线、数据读取和未决字段诊断；U03/U04在相应屏幕验收前补取47个待解rect与动画残缺参数。不能把空值直接设成0、统一白色255或浏览器默认click。
