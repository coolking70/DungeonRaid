# A01 原创美术重绘：棋盘图集（公开网页版用）

**执行者**：Codex（gpt-6-astra），使用 OpenAI 内置图像生成（imagegen）。
**前置阅读**：`AGENTS.md`；`docs/PLAN.md`。

## 背景

公开网页版（GitHub Pages）**不能包含原版美术**，因为原版贴图是 Firedrake Games 的版权素材。需要一套**原创**的替代图集。

调试界面按「原版 UV 布局」从一张图集上取图。所以只要新图集的格子位置和原版一致，渲染代码就不用改。

## 版权硬约束（必须遵守）

- **禁止**把原版贴图（`reverse/` 下的任何 png）作为图像生成的输入、参考图、img2img、描摹或配色取样来源。
- 只能根据下文的**文字描述**创作。
- 不模仿任何特定商业作品的画风，也不要出现「Dungeon Raid」或「Firedrake」字样。
- 不得修改或读取 `reverse/` 下的图片。读取 `data/enums.json` 中的文字描述是允许的。
- 生成的原始文件留在 Codex 的 `generated_images` 目录即可。项目只收录最终裁切、处理后的图块。
- `art/manifest.json` 中每个图块都要记录 `"source": "openai-built-in-imagegen"`，以及生成该图块时使用的提示词。

## 交付格式（硬约束）

### `art/tiles.png`

- 尺寸 2048×2048，RGBA。
- 布局等于原版 1024 图集**放大 2 倍**：原版每格 53 px，这里每格 **106 px**。
- 坐标一律以「原版 1024 坐标 × 2」计算。下表给出的都是原版 1024 坐标，`col` 和 `row` 从 0 开始：

| 内容 | 原版 1024 坐标（左上角） | 说明 |
| --- | --- | --- |
| 普通格 | x = 变体 × 53，y = 类型 × 53 | 类型：0 药水、1 骷髅（普通敌人）、2 金币、3 盾、4 剑。每种类型 8 个外观变体（变体 0–7） |
| 特殊敌人 e（1–32） | x = ((e−1) % 8) × 53，y = 672 + ((e−1) >> 3) × 53 | 4 行 × 8 列 |
| 链（Chain） | x = 512，y = 459 | 特殊格，可以连接任何类型的格子 |
| 奖杯（Trophy） | x = 618，y = 459 | 金色奖杯 |
| 命匣（Phylactery） | x = 671，y = 459 | 巫妖死后留下的魂器，红色宝石 |

- 每个格子在 106×106 区域内**画满**，包括背景色块。画面要在 64–128 px 的显示尺寸下清晰可辨。
- 图集里其余没有用到的区域保持全透明。

### 风格

- 统一的原创风格：暗黑奇幻的**像素风图标**，粗轮廓、高对比、少量色阶，像小尺寸手游图标那样一眼可辨。
- 每种普通格有固定的**背景色块**，方便快速分辨类型：
  - 药水：红色系背景，图案是红色药水瓶；
  - 骷髅：灰白色系，图案是白色骷髅头，正面、眼窝发光；
  - 金币：金黄色系，图案是金币；
  - 盾：蓝紫色系，图案是蓝色圆盾或鸢盾；
  - 剑：钢灰色系，图案是斜放的剑。
- 8 个外观变体可以是同一图案的细微变化，比如角度、高光、刻纹、色相微调。允许先生成一张基础图，再用程序生成变体，但变体之间必须看得出差别，同时一眼仍能认出是同一类型。
- **特殊敌人**：每种都是骷髅或怪物头像，要体现它的特征，并且彼此可区分。按 `data/enums.json` 中 EnemyType 的名称和描述来设计：

## 做法建议

1. 先只生成「风格锚点」：5 种普通格各 1 张，确定统一风格后再批量生成。
2. 每张生成图都由脚本（`tools/art/` 下的 Python，使用 Pillow / numpy）完成以下处理：裁切、缩放到 106 px（像素风用最近邻或适当的下采样）、统一背景、拼进图集。
   - 所有拼装步骤必须可以用 `python3 tools/art/build_atlas.py` 重跑。
   - 中间产物放在 `art/src/`，按图块分别保存成 png。
3. 生成预览图 `art/preview.png`：在 6×6 棋盘上随机摆放各类格子和若干特殊敌人，再按 64 px 显示尺寸各缩放一份，用来自检「小尺寸下是否清晰可辨」。

## 自检

- 写 `tools/art/check_atlas.py`，检查以下各项：
  - 尺寸为 2048×2048；
  - 75 个格位（40 个普通格、32 个特殊敌人、3 个特殊格）都非空，即 alpha 覆盖率大于 0.9；
  - 其余区域透明；
  - 32 个敌人两两之间在 64 px 下的平均像素差高于阈值，确保没有重复图；
  - manifest 中每个格位都有来源和提示词。
- **版权自检**：脚本计算 `art/tiles.png` 每个格位与原版 `reverse/` 图集对应格位（缩放后）之间的相似度，只读取像素做比较，不能用于生成。报告中给出最大相似度。如果某个图块与原版过于相似，必须重画。
