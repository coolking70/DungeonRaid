# A01 原创美术重绘：棋盘图集

完成日期：2026-10-15。状态：完成。使用 OpenAI 内置 imagegen，未使用 API／CLI 回退。

## 交付与风格

- `art/tiles.png`：2048×2048 RGBA，75 格，普通格 40、特殊敌人 32、特殊格 3；每格 106×106，其余区域透明。
- `art/manifest.json`：75 格均记录 `source: openai-built-in-imagegen`、完整生成提示词、坐标、处理源文件、变体参数及最终图块 SHA-256。
- `art/src/base/`：40 张已裁切、去背景、量化的原创中间图块；`art/src/*.png`：75 张最终图块。原始生成大图留在 Codex 的 `generated_images` 中，没有复制进项目。
- `art/preview.png`：种子 1001 的 6×6 混合棋盘，106 px 与 64 px 两份并排；包含三类特殊格及六种特殊敌人。
- `art/contact_sheet.png`：全部 75 格在 64 px 下的逐格联系表，含编号、名称和示例攻击／防御／生命数字。
- `tools/art/prepare_sources.py`、`build_atlas.py`、`check_atlas.py`：预处理、离线重建和独立验收。使用说明见 `art/README.md`。

采用原创暗黑奇幻像素图标：深色轮廓、最多 24 色的前景、固定类型背景色块、清楚的物体剪影。药水为红底红瓶，普通骷髅为灰底白骨与青色眼光，金币为金黄底，盾为蓝紫底，剑为钢灰底。特殊敌人按任务卡的王冠、尖刺、十字、独眼、毒雾、法帽、磁铁、狼首、缝线等特征分别生成。

普通格使用五张独立生成的锚点，通过最近邻旋转、亮度、少量色相变化和第八变体的镜像生成每类八个变体。最终以 53×53 逻辑像素构图、最近邻放大为 106×106。敌人轮廓按实际数字区域自适应缩放并上移，不裁掉冠冕、角或道具。

## 规格与来源证据

1. 图集尺寸、格数、坐标、设计要点：`docs/tasks/A01.prompt.md` 的交付表。普通格为 `(变体×53, 类型×53)×2`；敌人从原坐标 y=672 开始；Chain/Trophy/Phylactery 原坐标分别为 `(512,459)`、`(618,459)`、`(671,459)`。自检独立重建坐标表，不依赖构建脚本或 manifest 提供的坐标来判断正确性。
2. 敌人名称和描述：读取 `data/enums.json` 的 EnemyType。名称映射来源 `Tile::GetEnemyName @0x62bc8`，描述映射来源 `Tile::GetEnemyDescription @0x62be0`，原表 `g_enemyNames`／`g_enemyText`。例如 Boss 名称字符串偏移 `0x6fcfd`、描述 `0x6ff36`；Lich 名称 `0x6fe90`、描述 `0x71160`。Freezing 对应枚举 `ENEMY_FROZEN=8`，未改写枚举。
3. 数字留白：只读核对 `ui/main.ts` 的 `drawTile`／`text`：64 px 格中攻击和防御基线 y=14、字号 13；生命基线 y=58、字号 16。预览按这些位置和字号模拟，字体采用 Pillow 内置字体。106 px 图块中的静态留白矩形为 `[2,4,24,20]`、`[80,4,24,20]`、`[26,74,54,30]`，32 个特殊敌人与 8 个普通骷髅全部验证通过。
4. 每次实际生成提示词与缓存路径见 `art/generations.json`；没有任何参考图、img2img、商业画风名称、原版图像或原版取色输入。图像内没有游戏名称、商标或标签。

- MEDIANCUT 24 色量化把 Overseer 的少量琥珀眼色并入灰绿；改为 MAXCOVERAGE 24 色，恢复眼睛、火光等强调色。

## 原版数值相似度检查

任务卡同时要求「不得读取原图」与「版权自检只读取像素做比较」。这里把后者作为仅适用于最终检查的明确例外：生成及处理全部完成后，只有 `check_atlas.py --copyright` 读取原版 `tiles.png`，不显示原图、不保存裁片、不将任何原版像素用于创作或调色。

方法：对应原版 53 px 格位最近邻放大到 106，再把新旧图块缩到 64；分别合成到黑底／白底，计算 RGB 平均绝对差相似度 `1−MAE/255` 和 7×7 局部亮度 SSIM，取较大值。阈值在读取原版之前设定：相似度 <0.90 且 SSIM <0.80。

| 指标 | 最大值 | 对应图块 | 阈值 | 结果 |
| --- | ---: | --- | ---: | --- |
| RGB 像素相似度 | **0.776122（77.6122%）** | Assassin | 0.90 | 通过 |
| 局部 SSIM | **0.382985** | 普通骷髅变体 5 | 0.80 | 通过 |

75 格逐格结果见 `art/check_copyright.json`。没有图块达到重画阈值。数值是工程筛查指标，不表示版权相似比例，也不能单独构成法律上的原创性结论。
