## 目标

## 要做的事

做的顺序很重要：如果时间不够，按下面的顺序完成，没做完的部分在报告里写清楚，不要伪实现。

### 1. 三种菜单

满条时生成菜单候选，规则见 03 号规格的「满条与升级菜单」：
- 候选数量、来源池、权重、使用哪一路 RNG（SKILL / ITEM / UPGRADE）、遍历顺序；
- 属性奖励从第 42 号开始编号。

动作：
- 实现 `SelectMenuItem`（选中或取消候选）和 `ConfirmMenu` / `ChooseMenuOption confirm`（确认后应用）；
- 菜单 0（升级菜单）的两次选择，按点击顺序依次应用；
- `skip` 在原版允许跳过的菜单上保留，在不允许跳过的菜单上应当报错；**以伪 C 为准**。

### 2. 技能

- 获得：新技能等级为 1，冷却与充能按 03 号规格；已有技能升级到上限 10 级；处理 Sprint 例外和 Cunning。
- 施放：实现 `CastSkill`（来源分 manual 和 scroll），检查 `charge == cooldown` 以及 `CanActivate`。
- 42 个原生技能在 `Skill::Activate` 中的全部分支，包括：
  - Earthquake、Rune、Hack / Slash、Shock / Awe 的存档读取路径；
  - BoostDamage 等标志在当前回合与下一回合之间的轮换；
  - Wish 施放后被移除。
- 法力药水对技能充能的目标绑定，T04 已有一部分，需要补全。

### 3. 装备

- 复用 T05 的 `updateEquipmentStats` 和 `downgradeStep`。
- 强化：门槛、步长、`IsUpgradeAllowed`。
- 商店：逐槽生成装备，包括名称和词缀。
- 换装后的属性重算规则：
  - 护甲缺口保持不变；
  - HP 上限降低时只钳制当前 HP；
  - Quicken 开关会改变已有技能的冷却和充能。
- 卷轴：I1 仍未决，必须保留 `scrollFilter` 选项及其报错边界，不要自行发明筛选规则。

### 4. 职业与种族

- `NewGame` 能接受完整的职业配置：种族、优点、缺点、替换技能。
- 职业的首个技能在第一次升级菜单中出现，而不是开局就装备好。
- 十个优点、十个缺点、十个种族的能力，以及宿敌。
- Halfling 一次击杀 15 个以上时的装备成长，也就是 T04 留下的 `progression` 钩子。

### 5. 奖杯领取

- 实现 `ClaimTrophy`：随机让某个职业升级或解锁，规则见 05 号规格。
- 同步局内的 `classLevels` 快照。
- 长期 Profile 的持久化属于 T07，本卡只需要在状态里给出变化，并发出事件。
