## 给U03的接口

`mountApp(factories?: ScreenFactories)`接受 `main/settings/help/game-over` 屏幕工厂，每个得到 `AppServices`：session、assets、i18n、audio、stack、startNewGame。未注册时使用当前本地屏幕。U03可通过入口传入工厂，屏幕内部继续使用现有Screen生命周期与ScreenStack。

- `assets.ui.paint(ctx,id,x,y,w,h,state)`：语义绑定、九宫格、状态；`fill(...,fraction,vertical)`裁切填充，健康液面使用manifest.fillBounds。
- `assets.items.draw(ctx,String(icon),x,y,49,49)`：A03槽；`assets.tile(...)`：A01原生UV兼容。
- `i18n.t(key,params)` / `setLanguage('zh'|'en')`；`source(原文)`为已有显示名称查L01别名；装备必须用 `equipmentName`，不要core.itemName直接上屏。
- `candidateContent` / `equipmentLines` / `statRewardLines`用于完整说明与装备比较；后者在私有副本上调用无RNG的原有属性奖励函数，不修改live state。
- `GameAudio.play(id,-1)`请求独立UI变体，非负值为明确指定变体；`player`仍由S01实现。`log`保留2000条，`calls/played/counts`累计统计。
- `Tooltip`、`wrap/lines`在 `ui/widgets.ts`；ScreenStack语义保持U02设计。
- `PresentationTimeline`按FIFO展示，`current.tokens/falls`、`visuals`供绘制；UI时钟不能再次结算资源。`step().cosmetics`只读输出不需要写入存档。

## 已知差异与尚未完成的精确复原

1. **不是全部原生顶点/阶段的精确重放。** 连线使用法向/miter多边形保留已知9px宽、颜色、12.5px端点和alpha；原生斜转角额外退化顶点未逐顶点恢复。心跳完整cos实参仍未确认，当前保留节拍但颜色曲线为近似。
2. **粒子几何与部分SimpleLabel仍为近似。** 所有已消费随机样本可见，但粒子取样到顶点的关联、每类SimpleLabel原版烘焙文案/锚点和颜色尚未逐类复原；当前按规则事件绘制伤害、治疗、技能/敌人名和分数。不能将“各效果类别可见”视为每一个原版label调用点已经一一还原。
3. **特殊飞行覆盖不完整。** 普通资源token积分使用实际样本；旧存档无对应旁路样本时使用确定性中值回退。普通XP用原创骷髅图缩成39×23，未有独立XP飞行图。偷金、敌方接收token、特殊伤害抛物线等未全部恢复为原生轨迹，当前通过状态/数值/能力反馈表达；不影响资源或HP结算。
4. **结算是可操作的移植序列。** 死亡/Sprint分支、颜色、Pretzel最佳单链评级、计数/图标节拍已接；完整原生阶段顺序、所有图标计分意义及GameOver矩形仍未确认。当前明确采用装备→技能/优缺点→分数，并未声称其就是原生所有阶段。
5. **声音不是177调用点完整一一对应。** 已对实现的资源/选格/攻击/技能/菜单/部分特殊能力分支给出条件与测试，没有按事件名无条件铺声；仍有原生分支时序和同批多敌人效果关联待继续核验。没有伪造help31调用或声音COSMETIC兼容性。
6. 属性标签/返回控件、GameOver复合布局用移植布局；Help是可读的分页入口，不是完整原版自动帮助位/FIFO系统（后续U03）。部分奖励摘要只有两行，点击详情可看完整正文；字体大小/字宽与原版位图字体不同。
7. 生命液面遵循A02的实际fillBounds(6,33,64,57)，token目标仍保留原生HUD锚点；原创图的可见液体区域与原版完整64px填充高度存在美术适配差异。所有外屏幕、原生Android打包/音频听感与设备性能不在这次浏览器验证中。
