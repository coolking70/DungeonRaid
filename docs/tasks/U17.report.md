# U17 — 敌人数值与顶部信息栏

## 做了什么

用户截图中的问题确实存在。原版主题敌人攻击/防御/生命误用较粗的score字体，按错误字高缩放，导致上下两行拥挤、第一行被棋盘裁切；这是U15接入原版美术时的回归。已改用原版regular字体及原生Label度量，保留白/紫/红顺序、基线与右对齐，补回数字1光学校正。多位数、倒计时、命匣隐藏沿用原规则。

顶部「回合／等级／分数」是Web辅助信息，原版经典模式没有这条完整信息行。此前直接画在原版背景装饰线上，时钟也共用同一区域。现在保留信息，使用独立深色带、三栏；开启时钟时加第四栏。完整长数字缩放适配，不截断。菜单/技能命中、棋盘几何、游戏规则与存档均未改变。

## 原版证据

- `Tile::InitialiseLabels @0x63d3c`：字体指针 `Game+0x2c`，普通三值scale=.08，倒计时scale=.13，颜色白/173,177,255/255,70,60。
- `Game::SetFonts @0x2578c`：regular在+0x2c，score在+0x2454。`font.fnt` regular数字高15/lineHeight44；scale=.08对应8.727px可见字高；score数字高18，旧Web路径18/14*13=16.714px，超过12.8px攻防基线距离。
- `Font::AdjustCharacter @0x43980`、`Label::SetText @0x52814`、`Label::Render @0x52440`：原生Label的字符尺寸、半xoffset、半(width+xadvance)步进及缩放。regular默认spacing0见`Font::Font @0x43e90`。
- `Tile::UpdateText @0x63938`：右边界及attack字段/defence为1时的1.6px光学校正。基线、倒计时、命匣规则沿用U05已提取证据。
- `Interface::Process @0x49988`、`Render @0x490ec`：经典mode3不处理/显示挑战计分Label；challenge模式0显示分数及回合、模式1显示分数。Web辅助信息行不是原版经典HUD。
- 未修改`reverse/`、原图或字体文件；新增通用字体的score可见字高常量也从误写14更正为FNT实际18，敌人数值已独立走regular路径。
