## 实现

- `tools/extract-achievements.mjs`提取77个成就、8个排行榜到`data/achievements.json`。每项保留XML字段行号、Java数组行号/下标、枚举名；校验完整映射、唯一性、0号哨兵，可重复运行。
- `tools/i18n/achievements.mjs`合并标题/描述/排行榜及本卡UI文案，沿用L01完整英文去重与语义别名。`python3 tools/i18n/build.py`会自动重建此扩展，不会丢掉U06词条。人工译文在`tools/i18n/achievements-zh.json`；1–27按既有职业/种族译名生成。
- 语言包共1,191个规范词条、1,708个来源。L01校验器已纳入新数据的来源和格式检查，保留既有缺词、原文变更、残留英文等反例测试。新字体子集50,868字节，所需/实际覆盖1,688字符，其中汉字1,571；许可证文件未改动。
- 成就列表显示原文标题、中译、完整描述、gamerscore和百分比/进度条；每页3项，共26页。未解锁的秘密成就描述为`???`，达到100%恢复说明。**原版77项全部非秘密**，截图中的秘密标记只在隔离浏览器内存中临时设置，不改数据或正常存档。
- `AchievementNotices`为独立表现队列，每项显示3秒，多项FIFO；覆盖普通规则成就、职业里程碑及保存装备触发的72。重复队列/保存不会重复通知，读档不补播旧成就，清除档案清空队列；暂停时冻结。通知位于逻辑画面y=2…55，棋盘从y=80开始；无输入拦截，不遮棋盘。此时长/布局为移植选择，不冒充原生OpenFeint像素复刻。
- `ScreenStack`缓存淡入期间第一个完整点击，淡入结束后执行；移动超过8逻辑像素、取消、淡出输入不重放；跨淡入终点的按下等释放再执行。相同淡入期间的重复点击合并，重放后250ms内抑制重复按下，避免双击穿透。导航清旧缓存，暂停不推进时钟。
- 设置新增「音效：原版 / 合成」，默认原版，localStorage键`dungeonraid.soundStyle`；预先准备两套缓冲，切换立即停止旧声音，后续直接选新缓冲，加载中的切换不会被覆盖。原版样本缺失/解码失败仍回退合成，静音与音量保持原有行为。
- 每次`vite build`用本机已有Pillow生成无损WebP到`ui/generated/`；PNG源文件保留，生产先加载WebP，解码失败仅重试一次PNG。逐像素比较解码RGBA与PNG完全一致。开发服仍用PNG；没有添加依赖。
- Easy职业最佳分行为符合原版，**未修改规则引擎**；统计页标注「简单难度不计入职业最佳分」。Easy仍增加局数、击杀，并进入Easy本地高分榜。
