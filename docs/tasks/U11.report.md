# U11 — 属性说明与相邻界面核查报告

## 做了什么

- 恢复8种升级属性选项的实际效果、旧值→新值和明确的额外奖励概率，保留基础/装备的原版区分、100%显示上限及椒盐卷饼例外。
- 接入20种强化功能说明，恢复旧值→新值、百分比单位、每格额外收益的0.25倍换算。新添属性显示新增值。
- 装备详情恢复毒素持续时间、再生触发时间、尖刺/钝化作用及每格收益等完整文案。商店保留卷轴标记、展示卷轴效果和被替换装备，用红/绿比较变差/变好（包括属性移除）。
- 恢复原版属性面板17行及装备贡献颜色，补回破甲率、护甲耐久率，明确各种额外奖励“概率”。第六个职业图标可查看当前种族能力、天赋和缺陷。
- 技能升级显示冷却前后值；局内技能提示补上“冷却”标签并隐藏无冷却技能的无意义负数。职业技能页新增完整说明入口。
- 长提示分页，翻页手势不会穿透到奖励选择或棋盘；不再静默截掉第24行以后的信息。
- 未修改核心规则、存档格式、逆向材料或美术资源；未处理/覆盖既有U09待提交文件。

## 核查范围与结果

本次沿属性信息链路核对了升级、强化、商店、装备详情、局内属性/角色、技能提示，以及职业编辑的技能/种族/天赋说明入口。确认的同类遗漏已按上文补齐。现有种族、天赋缺陷、技能选择、教程及宿敌说明已有内容入口；本次没有重写其规则或文本。

长详情分页、候选短摘要、商店比较整行着色属于当前Canvas的布局适配；原版提供的信息和数值语义保持一致，不声称像素级复刻。
