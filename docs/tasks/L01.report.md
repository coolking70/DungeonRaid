## 证据与翻译取舍

权威文本来自`data/ui-strings.json`及其引用的enums/items/classes文本对象；校验会独立遍历这三个源文件的全部`text`对象，防止只检查翻译目录而漏掉输入。每个来源与原文、native证据、长度依据逐一比较。

技能与实体名：Skill::GetSkillName @0x5ff18 / GetSkillDescription @0x5ff2c；Tile::GetEnemyName @0x62bc8 / GetEnemyDescription @0x62be0；CharacterClass::GetClassName @0x35e94等。技能40/41采用原生表的Shock/Awe，不新增SWIG枚举值。

装备名：Item::GenerateName @0x4c35c的`%s  %s`先前缀再名词。中文`{prefix}{noun}`，例“传奇长剑”；英文保留两个空格。技能卷轴用“{skill}卷轴”。种族职业名依据StatsMenu::Process @0x61d84与GameOverScreen::Initialise @0x457d4，保留种族在职业之前。

Hack/Slash区分为“劈斩/横斩”；Shock/Awe为“震击/震慑”；Phylactery统一“命匣”；UP为“强化点”，XP为“经验”，armour为“护甲”，shield为“盾牌”。Pretzel保留卷饼笑点。61段开场故事保留第二人称和原文的荒诞、讽刺，不把它们缩成泛用英雄背景。原文数值和条件按文本翻译，不在翻译中重写规则。

OpenFeint、PlayHaven与26个字母键逐条白名单；没有全局放过所有英文。音效/纹理`resourceName`的译文仅是显示标签，不得用来替换资源加载标识。未保留英文缩写XP/GP/UP/HP作为中文按钮或属性文本。

## 给U02的接入说明

语言包结构是`{locale, messages: Record<string,string>, sources}`，不要把sources或元数据当显示文字。安装en/zh后，必须同时加载catalog的`aliases`、`sourceToKey`和`entries[*].placeholders`，否则`baked.2`等旧来源ID与动态精度不会正确解析。当前U02的`install`/`installCatalog`接口已能读取此结构；本卡仅提供数据和参考适配器，没有修改ui文件。

独立参考用法：

```ts
import en from '../data/i18n/en.json';
import zh from '../data/i18n/zh.json';
import catalog from '../data/i18n/catalog.json';
import { createI18n } from '../tools/i18n/runtime.mjs';

const i18n = createI18n({ en, zh, catalog }); // 默认zh
const title = i18n.t('ui.menu.newGame'); // 新游戏
const sameTitle = i18n.t('baked.2');     // 同一规范词条
const level = i18n.t('ui.level', { level: 7 }); // 7级
i18n.setLocale('en');
const english = i18n.t('ui.menu.newGame'); // New Game
```

- 切换语言后重新测量和换行，重绘所有当前屏幕/弹层；语言偏好保存由U02负责。参考适配器默认zh，未知语言回到zh。
- 回退顺序：当前语言 → 英文 → 请求键。有效空串保持空串，不使用`||`误判缺译。参数缺失或类型错误抛错，调用方需按catalog传齐。
- 别名例如`skill.12.name`、`skill.12.desc`、`enemy.4.desc`、`item.prefix.37`；底层真正存储键可能不同，必须经过aliases解析。`catalog.sourceToKey`覆盖全部1,541个输入ID。
- `%.*f`的参数包括数值与精度，例如`{value: 1.25, valuePrecision: 2}`；`argumentOrder`列明原生参数顺序。名字/描述参数必须由调用者先翻译，适配器不会再次解释插入文本里的占位符。
- 加载字体可用Vite的`?url`导入WOFF2，通过FontFace API加载并加入`document.fonts`，再设置Canvas的`12px "DungeonPixel"`。等待加载完成再进行文字测量；加载失败可回退`monospace`，但应重新测宽，不能沿用像素字体的溢出报告。CSS默认可写`font-family: DungeonPixel, monospace`。整数倍字号更适合像素字体。
- catalog含完整证据，较大；生产构建可仅取messages、aliases、sourceToKey和placeholders，来源证据无需全部进入首屏包。本卡保留可审计完整文件。
- U02额外新增的本地设置、错误提示等不属于本卡原文清单；接入方新增到目录后需重跑字符收集。当前子集覆盖的是这两份语言包和固定符号，不宣称覆盖未来文案或任意玩家姓名。
