# U08 奖杯条件与首页布局

2026-10-16，已完成。

## 实现与证据

- 核对 Game::MatchTile @0x2ac40：正常结算的非普通骷髅统一进入特殊奖励尾部，未按特殊敌人种类或宿敌筛选。难度字段必须>0；Sprint 用 RandI(0,100,0)<50 推进计数；到期且有职业成长资格时掉奖杯，每局最多3个，之后重置为 RandI(20,30,0)。点击领取后的职业升级/随机解锁规则来自 ProcessInput @0x330c0。详情补充到 spec/05 和中英文游戏内解锁说明。
- MainMenu::MainMenu @0x53384 的原始文字贴图范围直接套用为移植版矩形按钮，造成 New Game/Challenge 重叠9px、Challenge/Tutorial 重叠9.5px。旧命中按按钮顺序查找，重叠处可能进入上一个入口。
- 统一左侧8个按钮为144×34，左距12、首行y94、行距43（净间隙9px）。绘制/命中使用同一范围。入口行为和右下声音按钮保留；错误提示横向避开按钮。新布局明确记录为移植版调整，原生提取数据及 reverse/ 不改。
- 新增33项规则回归覆盖32种特殊敌人的正常奖励结算与普通骷髅排除；未改规则引擎。
