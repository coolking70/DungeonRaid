# S01 原创音效：程序合成 38 类、70 个变体

**执行者**：Codex（gpt-6-astra）
**前置阅读**：
- `AGENTS.md`
- `docs/P3-PLAN.md`
- `docs/spec/12-audio.md`
- `data/sounds.json`：音效 id、名称、变体数、时长、`designDescription`、触发点

## 约束

- **完全原创**：不得读取、分析、转写或模仿原版 `reverse/apktool/res/raw/*.ogg` 的波形或频谱。
- 只能依据 `sounds.json` 里的名称、时长、文字描述（`designDescription`）和触发语义来设计。
- 不引入任何第三方音频文件或库。合成器自己写，参考 sfxr 的参数模型：
  - 波形：方波 / 锯齿 / 正弦 / 噪声；
  - 包络：attack / sustain / decay；
  - 频率滑动、颤音、占空比、低通 / 高通、相位器、重复。

## 要做的事

1. **`src/audio/synth.ts`**
   - 纯 TypeScript 实现，参数 → `AudioBuffer`，使用 WebAudio 的 `OfflineAudioContext` 或者手写采样渲染均可。
   - 渲染必须是确定性的：噪声使用带种子的 PRNG，同一份参数每次渲染结果完全相同。
2. **`src/audio/player.ts`**
   - 预渲染并缓存全部音效。
   - `play(soundId, variant?)`：变体规则按 `sounds.json` 来；规格说由 COSMETIC 选择的，播放器只接受调用方传入的变体号，自己不做随机。
   - 全局音量、静音。
   - 并发上限按 12 号规格（8 路），超出时的抢占策略写在报告里。
   - 浏览器要求用户交互后才能播放，处理好 AudioContext 解锁。
3. **`data/sfx.json`**
   - 每个音效、每个变体一组合成参数。
   - 时长尽量接近 `sounds.json` 中的原版时长，同一类音效的响度保持一致。
   - 同一音效的多个变体在音高或音色上要有差别。
4. **试听页**
   - `tools/sfx-preview/index.html` 加 `main.ts`，用 `npx vite tools/sfx-preview` 启动。
   - 列出全部音效与变体，能逐个播放，显示参数，并提供「全部顺序播放」。
5. **单元测试** `test/audio-synth.test.ts`
   - 参数校验；
   - 确定性：同一份参数，渲染结果哈希一致；
   - 时长误差在容差内；
   - 峰值不削波；
   - 38 类、70 个变体与 `sounds.json` 一一对应。
