## 1. 成就原文与中文翻译（重点）

- **原文来源**：`reverse/apktool/res/raw/openfeint_offline_config.xml`。共有 77 个 `<achievement>`，字段包括 `id`、`title`、`description`、`gamerscore`、`is_secret`、`position`；另有 8 个 `<leaderboard>`。
- **映射**：成就枚举值与 OpenFeint id 的对应关系，见 `reverse/jadx/.../DungeonRaidSurfaceView.java` 中的 `mAchievements` 数组（下标即枚举值）。以此建立「枚举 ↔ 原文」的对应。核对 78 个枚举项中缺失的那个（下标 0 为空），以及成就 45（ACH_I_SEE）的情况。
- **提取**：写 `tools/extract-achievements.mjs`，生成 `data/achievements.json`，每条带来源（xml 行号、Java 下标），可以重复运行。
- **i18n**：
  - 把标题和描述并入 `data/i18n/en.json`、`zh.json`，按 L01 的键命名约定。
  - 中文翻译要符合 `docs/i18n-glossary.md` 的术语，保留原文的幽默与双关；实在无法直译的，在报告里说明取舍。
  - 修改后运行 L01 的检查工具。
  - 新增的汉字要进入字体子集：运行 `tools/i18n/subset-font.py` 重建子集，确认覆盖率测试通过。
- **界面**：
  - 成就列表显示标题、描述、分值（gamerscore）和进度。
  - 秘密成就（`is_secret`）在解锁前隐藏描述，显示为「???」。
  - 局内解锁成就时弹出简短的提示条，对应原版 OpenFeint 的成就通知：位置不遮挡棋盘，几秒后自动消失；同一时刻有多个时依次显示。
  - 8 个 leaderboard 的名称如果和高分榜的 6 个类别对得上，就用原文命名（加中文翻译），并在报告里写明对应关系。

## 2. 淡入期间的点击

- **现状**：屏幕淡入约 1 秒，期间点击被忽略，首次点击常常看起来没有反应。
- **处理**：
  - 先查原版：`FadeOut` / `Show` 期间是否接收输入（ScoreScreen、HelpMenu、Menu 等），以证据为准。
  - 原版也忽略的话，把淡入期间的点击缓存下来，淡入完成后再执行；或者只在淡入的前 0.15 秒忽略。在报告中说明选择的方案。
  - 不允许出现双击触发两次的情况。

## 3. 图集体积

- `art/items/items.png`（约 1MB）和 `art/ui/ui.png`（约 540KB）**在构建时**转成无损 WebP（像素风必须无损），PNG 源文件保留。
- 浏览器不支持 WebP 时回退到 PNG。
- 本机 Pillow 是否支持 WebP 要先确认；不支持就改用其他无依赖的方式，并说明。
- 在报告里给出转换前后的首屏下载体积。

## 4. 音效切换

- 设置中增加「音效：原版 / 合成」选项，默认原版，保存在本地，切换后立即生效。
- `src/audio/player.ts` 已经支持原版样本，找不到时回退到合成；本项只需要增加切换。

## 5. Easy 难度的职业最佳分

- **现象**：Easy 难度局终后，档案里职业的 `bestScores` 仍是 0。
- **任务**：查原版（`CharacterClass` 的统计更新、`ScoreScreen::AddScore`、`CheckEndGame` 等）在 Easy 下是否记录最佳分和局数。
  - 原版确实不记录：保持现状，在设置页或统计页标注「简单难度不计入最佳分」，标注要带证据。
  - 原版会记录：修复，并补测试。
