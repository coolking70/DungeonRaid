# U18 — 可独立关闭的辅助显示

## 做了什么

设置页新增「辅助显示 / Display aids」子页，提供三个独立开关，默认全部开启以保持已有用户的显示习惯：

- 顶部辅助信息栏：关闭回合/等级/分数及整行底色/分栏。时钟保持独立开关；开启时钟时在右侧单独显示。
- 连线伤害提示：关闭棋盘底部的连线长度、伤害、吸血/反伤汇总。错误、保存失败、无可连提示仍有效。
- 奖杯击杀计数：同步隐藏统计和属性页的剩余击杀数、点击说明入口；属性页保留原有17行，不隐藏棋盘上的奖杯。

三项可任意组合、重新开启，选择即时生效并保存到浏览器偏好。切换不改变对局、随机数、伤害、奖杯计数/掉落/领取。没有设置一个隐含修改规则的「原版模式」。

## 依据与实现

- 本功能来自用户要求，属于Web配置，不推断原版有这些选项。原版17行属性来源为`StatsMenu::CreateLabels @0x61178`、`Show @0x614bc`，隐藏奖杯行仅不附加U13辅助数据。
- `ui/preferences.ts`管理既有3个偏好与新增`statusStrip/chainSummary/trophyProgress`，分别存入对应`dungeonraid.*`键。缺少键使用默认值，异常存储允许本页切换；不写游戏存档。
- `ui/front-screens.ts`提供入口/开关说明及统计页可见性；`ui/app.ts`控制连线汇总和属性页；`ui/content.ts`允许省略额外奖杯行；`ui/hud.ts`控制顶部带/独立时钟。
- 时钟是独立原有功能，原版`SetClockState @0x487dc`/`SetClockString @0x4887c`也维护独立状态与Label。关闭辅助信息后的右侧位置仍为Web布局适配，不声称完全复刻原时钟贴图。
- 10条双语提示、6个新增汉字纳入字体子集，覆盖1710/1710。英文标题原拟Extra displays会被原版标题字体截断，已改为Display aids并重新验证。
- 未修改`src/core/`、`reverse/`、原APK/原图或存档格式。
