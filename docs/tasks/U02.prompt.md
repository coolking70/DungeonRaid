## 目标

搭好 P3 的界面框架，让 U03（局外屏幕）和 U04（局内 HUD 与动画）只需要往里加屏幕和效果。本卡不追求视觉还原，验收重点是架构正确、现有玩法不退化。

## 要做的事

1. **画布与缩放**
   - 以 320×480 逻辑坐标作画，按 10 号规格的 2:3 视口规则缩放并留边；高分屏下按 devicePixelRatio 清晰渲染。
   - 输入先减去视口偏移，再归一化到逻辑坐标。
   - 窗口尺寸变化时只重建视口，不重新开局。
2. **屏幕栈**
   - 实现 `Screen` 接口：enter / exit / update(dt) / render / input。
   - 支持入栈、出栈、替换，以及淡入淡出过渡，时长取自规格。
   - 先放占位屏幕：主菜单、局内、局终、设置。局内屏幕在本卡沿用现有调试台的玩法，但要搬进新框架。
3. **精灵与图集**
   - 编写图集加载器，读取 `art/tiles.png`（A01，2 倍）以及将来的 `art/ui/ui.png`（A02）和 `art/items/items.png`（A03），三者均带 manifest。
   - A02 / A03 尚未交付时，用纯色块加文字的占位绘制，不能报错。
   - 本地 dev 模式下，`?art=original` 可以切换到原版贴图做对照（沿用现有 `@sheet` 机制）。
4. **表现时间线**
   - 引擎事件进入有序的表现队列；每个动画有独立的 elapsed 和完成条件，支持积分式、固定时长补间、逐帧吸附三种（见 U01 建议）。
   - 维护「规则快照」与「显示快照」：表现可以延后播放，但不得改变引擎的 `EffectConsumed` 和菜单提交的规则顺序。
   - 暂停和恢复会冻结表现时钟。
   - 先实现下落和 token 飞行两种动画，验证框架；其余动画在 U04 实现。
5. **音频接口**
   - 定义 `AudioPort`：`play(soundId, variant)`、音量、静音。
   - S01 正在并行实现 `src/audio/player.ts`。本卡用一个空实现占位，并写好从引擎事件到音效 id 的映射骨架，依据 12 号规格的触发表；真正接入合成器放到 U04。
6. **i18n 接口**
   - 定义 `t(key, params)` 和语言切换，设置保存到 localStorage。
   - L01 正在并行生成 `data/i18n/*.json`。本卡先读取 `data/ui-strings.json` 的英文作为回退；文件存在时自动使用 i18n 数据。
   - 字体加载接口预留 `fonts/fusion-pixel-12-subset.woff2`，文件不存在时回退到系统字体。
7. **保留调试台**
   - 现有调试台的全部能力（日志、种子、职业 / 难度 / 模式、存档、档案、I1 钩子、无可连提示）在 `?debug` 下仍可使用，可以作为一个覆盖层或独立屏幕。
   - 公开版默认进入新框架。
8. **引擎扩展**（按需，只增不改）
   - 如果表现层需要引擎在已经消费的 COSMETIC 抽样中暴露结果值，可以在 `src/core` 中以只增不改的方式扩展事件字段，并补测试；不得改变任何规则或 RNG 顺序。
   - 保持 `npm run check` 通过，整局模拟的哈希不变。
