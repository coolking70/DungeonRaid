# A02 原创界面美术：HUD、按钮、面板、职业 / 种族 / 属性 / 优缺点 / 技能图标

**执行者**：Codex（gpt-6-astra），使用 OpenAI 内置 imagegen
**前置阅读**：`AGENTS.md`、`docs/P3-PLAN.md`、`docs/tasks/A01.prompt.md`（版权硬约束和工作方式完全沿用）、`docs/tasks/A01.report.md`、`docs/spec/13-art-requests.md`（本卡的需求来源）、`docs/spec/10-ui-screens.md`、`data/ui-layout.json`。

## 版权硬约束

与 A01 相同：
- 禁止把 `reverse/` 下的任何图片作为生成输入、参考图、img2img、描摹或取色来源；
- 只能依据 13 号规格的文字描述创作；
- 不画文字，所有标题和按钮文字由界面用字体渲染；
- 不出现 Dungeon Raid 或 Firedrake 字样；
- manifest 中每个图块都要记录 `"source": "openai-built-in-imagegen"` 和提示词。

## 范围

按 13 号规格逐项制作。13 号中标为「未决 / 暂不最终切图」的复合面板，先做**可 9-slice 拉伸的通用面板和边框**，不要猜它的最终尺寸。

1. **语义图标**（约 90 个）：
   - 职业 10 个；
   - 种族头像 10 个；
   - 优点和缺点共 20 个；
   - 技能 42 个；
   - 属性 8 个。

   风格与 A01 的棋盘图块统一：暗黑奇幻像素风，粗轮廓，高对比。
2. **HUD 部件**：
   - 资源条的槽和填充：经验、金币、强化三色；
   - 生命和护甲的显示部件；
   - 技能按钮框，包含充能中、可施放、禁用三种状态；
   - 状态图标：毒、燃烧等；
   - 菜单 / 统计按钮。
3. **通用界面**：
   - 按钮，包含常态、按下、禁用三种状态，可 9-slice；
   - 面板和对话框底；
   - 折叠菜单的选项底；
   - 标签页；
   - 滚动条；
   - 锁图标、勾选、返回箭头等小部件；
   - 主菜单背景，竖屏 320×480 逻辑尺寸，按 2 倍出图。

## 交付格式

- `art/ui/ui.png`：**2 倍分辨率**的图集，尺寸自定，最大 2048×2048，RGBA。
- `art/ui/manifest.json`：每个元素包含：
  - id，使用 13 号规格或 `ui-layout.json` 中的元素 id；
  - 在图集中的矩形（2 倍像素）；
  - 逻辑尺寸；
  - 是否 9-slice，以及切片边距；
  - 状态变体；
  - 来源和提示词。
- `art/ui/src/*`：单个图块的中间产物。
- `art/ui/preview.png`：按逻辑尺寸摆出主菜单、HUD 和一个折叠菜单的示意版面，只用来检查风格和清晰度。
- `art/ui/contact_sheet.png`：全部图块的总览图。
- 生成脚本：`tools/art/ui_build.py`、`tools/art/ui_check.py`，必须可以重跑。

## 自检

`ui_check.py` 检查以下项目：
- manifest 覆盖 13 号规格中全部必做项；
- 图块非空，没有越界和重叠；
- 9-slice 边距合法；
- 90 个语义图标两两之间在 32px 尺寸下可区分；
- 与原版图集对应区域的相似度筛查：只读像素做比较，方法同 A01，阈值 0.90。
