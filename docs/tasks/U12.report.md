# U12 — 划线详情与回合/概率核查报告

## 修改与结论

1. 修复划线过程中误弹详情。原逻辑每换格就重启0.45秒长按计时；现在仅允许初始格静止查看，一旦发生拖动，本次手势不再弹详情，即使回退成一格。已有详情在开始拖动时立即隐藏。保留静止单点/长按查看，容许8px逻辑坐标抖动。
2. 未中毒时隐藏中毒行；没有能力倒计时时也隐藏空行。有状态仍显示。原版敌人Tooltip本身没有这些动态战斗数值，它们是重构版辅助信息，不能无条件显示0/0/0造成混淆。
3. 确认升级/强化不独立消耗回合：消除→资源结算→奖励菜单→继续本回合敌人攻击→回合结束。多个菜单也不重复攻击。施放附魔打开强化菜单，确认后不新增敌人回合。无需改变规则引擎。
4. 属性+5%是额外资源奖励概率增加5个百分点（如20%→25%）；同类结算从第4个开始逐个抽签，成功额外一份资源，不影响格子生成。力量/敏捷/体质/幸运分别影响经验/盾牌/药水/钱币，魅力影响四者。盾牌额外奖励仍遵循先修复、满护甲才加强化点的结算规则。

## 原版证据

- 首次特殊敌人提示：Game::ProcessInput @0x330c0；移动隐藏：ProcessTileSelection @0x2c8dc；内容范围：Tooltip::Show(EnemyType) @0x662f0。
- 菜单只应用奖励：FoldoutMenu::Process @0x41fc4；资源触发菜单：AddResource @0x32210；攻击阶段/回合恢复：ProcessInput @0x330c0（Game+0x5f74、+0xbc5c）、Game::Process @0x339ac、EndOfTurn @0x3289c。
- 附魔：Skill::Activate @0x60210 case10；加概率：Skill::GetStatChance @0x5ff0c常量5；额外奖励：MatchTile @0x2ac40，计数阈值4，RandI(1,100,5)，额外AddToken；Daring阈值10覆盖100%。
- 8px容差与0.45秒长按是当前Web交互适配值，不声称来自原版。规则、逆向文件、存档格式均未修改。
