# U03 局外屏幕：主菜单、模式与难度、职业配置、教程 / 帮助、高分榜与成就、设置

- **阶段**：P3，在 U04 之后执行。
- **执行者**：Codex（gpt-6-astra），可以用 `develop-web-game` 技能截图自检。
- **前置阅读**：
  - `AGENTS.md`、`docs/P3-PLAN.md`；
  - `docs/spec/10-ui-screens.md`、`11-animation.md`、`12-audio.md`；
  - `docs/tasks/U02.report.md` 和 `U04.report.md`，重点看给 U03 的接口：屏幕注册、素材 / 文本 / 音频 API；
  - `docs/tasks/T06.report.md`：职业编辑器接口，包括 `isPerkSlotUnlocked`、`canChangeRace`、`replacementSkillsAllowed`、`validateConfiguration`、`getSkillPool`；
  - `docs/tasks/T07.report.md`：档案、成就、高分榜接口。

## 目标

做完本卡后，从打开网页到开始一局、局终后返回，整个局外流程都是原版风格的完整界面：
- 美术用 A02 的原创图集，主菜单背景为 `main.background`；
- 文本默认中文，可以切换英文；
- 音效按 12 号规格接入；
- 公开版具备上线条件。

## 要做的事（按 10 号规格的屏幕清单与状态机）

1. **主菜单**
   - 包括继续、新游戏、挑战、教程、高分榜、设置 / 声音开关。按钮的位置、禁用条件（例如没有存档时「继续」不可用）、淡入淡出都按规格。
   - 原版的 OpenFeint / More Games 等在线服务入口**不实现**，在报告中注明。
2. **新游戏流程**
   - 新游戏确认框，用于覆盖现有进度时；
   - 模式选择：Classic / Dungeon Sprint / Pretzel Hero。原版的 Challenge 入口与标题烘焙字改为字体渲染；
   - 难度选择；
   - 职业配置屏幕（`ClassScreen`）：
     - 标签页：职业、种族、优点、缺点、技能（替换技能）。
     - 锁定和解锁状态取自档案中的职业等级，按 T06 编辑器接口判断可编辑的内容。
     - 显示职业等级、局数、最佳分。
     - 确认后以 `NewGame.character` 开局。
   - 名字输入：原版有屏幕键盘，Web 版可以用原生输入框代替，但要保持原版的长度限制，并在报告中说明这一差异。
3. **教程 / 帮助**
   - 实现 `HelpMenu` 的提示队列：一次性提示位、淡入淡出、显示条件，按 `UpdateHelpState` 和规格。
   - 主菜单「教程」入口，以及开场介绍（Intro）。
   - 设置中提供「重置帮助提示」。
4. **高分榜与成就**
   - 高分榜共 6 页，每页 10 条。拖动、速度、吸附按 `ScoreScreen::Process` 的逐帧公式实现，**不要换成固定时长补间**。
   - 每条记录显示：名字、回合、分数、技能图标，Pretzel 页显示 Avg / Max / Total。
   - 成就列表：已解锁 / 进度 / 未解锁。成就 45（ACH_I_SEE）没有触发证据，标注为不可获得。
   - 职业解锁通知（Unlock 屏幕），以及统计（Stats）屏幕。
5. **设置**
   - 语言（中 / 英）、音量、静音。
   - 原版游戏菜单里的 Clock / Dimming / Smooth 选项：U04 已在局内菜单实现，这里统一保存与读取。
   - 重置帮助提示。
   - 清除档案：需要二次确认，并且在报告中写明会删除哪些数据。
6. **局终返回**
   - 局终结算后回到主菜单或高分榜，流程按规格。
   - 新纪录高亮。
7. **补齐未决矩形**
   - 本卡涉及的屏幕中，U01 留下的未决矩形，由本卡回到原生伪 C 补齐，写回 `data/ui-layout.json` 和 10 号规格并附证据。
   - 查不到的保留 null，在界面中采用合理布局，并在报告中列出。**不要凭印象编坐标。**

## 验收

- `npm run check` 通过，整局模拟的哈希不变。
- 公开构建通过：`npx vite build --mode pages && node tools/check-dist.mjs`。
- 截图放在 `docs/tasks/U03.shots/`，每张都要有桌面和手机（375×812）两个版本，中英文各取若干：
  - 主菜单；
  - 模式与难度；
  - 职业配置的各个标签页，含锁定状态；
  - 教程提示；
  - 高分榜（含 Pretzel 页）；
  - 成就；
  - 设置；
  - 清档确认。
- 截图控制在合理体积：用 JPEG 或缩小后的 PNG，总量不超过约 3MB。
- 端到端流程：
  1. 首次打开（无存档）；
  2. 教程提示；
  3. 选择 Sprint + Hard + 配置职业；
  4. 开局；
  5. 刷新后继续；
  6. 死亡；
  7. 高分榜出现新纪录；
  8. 返回主菜单。

  全程无报错。
