# U07 解锁说明、各级奖励与脚本教程示例

日期：2026-10-16。已完成用户要求：补齐职业/种族解锁说明、各级奖励查看入口，并为23页教程加入实时脚本绘制的图像示例。规则引擎、原APK及 reverse/ 均未修改。

## 实现

- 职业配置页增加「解锁说明」「各级奖励」。非简单难度、特殊敌人、奖杯、随机解锁/当前职业升级、每局最多3奖杯均有解释，并区分跨局职业等级与单局经验等级。
- 奖励页复用原版已提取的双语 GetLevelDescription 文案及动态名称。非冒险者1–10级逐项可点，包括尚未解锁职业；显示已达到/预览。冒险者只展示1级默认优缺点共享说明，并说明没有2–10级奖励、固定人类。10级另明确共享技能池与开局装备技能的区别。
- 种族页点击锁定图标也可查看解锁来源：对应职业、当前等级/5、默认种族从职业解锁起即可使用，以及5级才共享给其他职业。保留当前职业达到5级才可换种族的第二道门槛。详情同时展示种族能力与宿敌名称/描述。
- 长详情按19行分页；中文、英文使用同一布局计算，避免说明静默截断。种族页为摘要，详情按钮提供完整正文。
- 教程23页由 `ui/tutorial-examples.ts` 每帧绘制，使用 `tileUV`、`Assets.tile`、语义图块ID、`Atlas.paint/fill` 和现有 `drawArrow`。局部布局统一为272×170，方块行居中计算。没有教程截图素材、离线生成图册、复制图集UV或依赖屏幕坐标的截屏裁切。未来美术按游戏现有图集/manifest约定替换时，示例同步使用新素材。
- 示例标注为图示/示例数值，读取自身局部数据，不使用活动对局对象、游戏RNG或计时器。第0页目录说明调整为“开始练习”，局内气泡继续沿用原版文本。技能持续示例用伤害强化，符合原版持续效果。
- `ui/help-copy.json` 保存新增双语移植文案及来源声明；原版奖励文案仍取既有catalog。字体生成和覆盖校验增加该文件，新增11个字符，最终1699字符、字体51216字节。
- `render_game_to_text` 增加教程页/示例类型、奖励预览、种族查看ID、详情页与正文，用于真实输入回归。
