# U15 — 原版美术统一默认使用

## 完成内容

- 按用户要求，将其余原版美术接入并作为默认：菜单/职业/种族/天赋/缺陷/技能/属性图标、400个装备图标、HUD与效果、三套位图字体、启动图和应用图标。
- 原版7张游戏贴图、3个FNT及96px应用图标共11个文件逐字节比对来源一致。新增文件与U14既有tiles.png一并记录在`art/native/sources.json`；FNT禁止Git文本转换以保持原字节。
- 原版菜单512px、棋盘和装备1024px；建立独立映射，不能复用重绘图集坐标。`Atlas`支持多纹理、1倍/2倍源像素、九宫格、原色调制和缓存。
- 修正原版实心技能槽覆盖图标的绘制顺序；原版血瓶先空瓶后向上填充，不再覆盖已填生命值。主页直接显示原版背景和标志。
- 英文标题/正文与敌人数值使用原版位图字形；中文及原版缺字仍保留Fusion Pixel回退。动态双语按钮保留，未使用英文烘焙标签替换中文。
- 教程仍由脚本实时绘制，自动读取当前Assets。`?art=redrawn`保留此前整套重绘供对照；默认界面没有请求重绘UI/装备图片。
- 未修改`reverse/`、APK、纯规则引擎、存档格式及随机数行为。

## 原版证据

- `CharacterClass::GetIconCoords @0x35c00`及Class/Race/Perk/Flaw包装函数；`QuadStrip @0x5b5b4`默认512px；`data/ui-layout.json.artSlots`的menus归一化UV除2。
- `Skill::GetIconUVs @0x600cc`、`Upgrade::GetIconUVs @0x67440`：图标网格步距50.03、内偏移1、跨度49；装备20×20网格。
- `NameScreen::MakeButton @0x56c04`：menus(194,1,53,53)，九宫格边距5、RGB(150,150,255)；`MakePanel @0x56dc4`：menus(50,1,53,53)，RGB(95,95,150)。
- `Interface::Interface @0x4a414`：技能底框(201,382,53,53)、顶部/底部HUD；HUD定位沿用U01数据。空瓶底图取对应HUD位置(239,438,71,64)，满瓶(325,447,71,64)。
- `Tile::SetFlameVisibility @0x62de8`、`SetFreezeVisibility @0x62e94`、`Tile::Tile @0x63f44`：火焰、雪花、死亡叉；`Game::AddFlare @0x29894`及`Game::Start @0x260ac`：闪光与盾碎片。
- 3个原版BMFont描述文件、`Font::AdjustCharacter @0x43980`；启动图源于原Java启动布局；APK `AndroidManifest.xml`指定`@drawable/icon`。

## 适配与未决问题

- 双语按钮、Tooltip分页、附加中毒徽记和新增页面继续采用现有Web布局；菜单选择/禁用状态、字体字号也为适配。不是原APK逐像素、逐帧复刻。
- 原版字体不含中文，因此中文回退属于必要兼容。页内原版缺字文本也回退，不改变文案内容。
- OpenFeint停用服务的独立SDK页面未在重构版实现，不接入其素材或联网入口。原版资源权利归属不变。
- 原APK精确截图对照和Android真机仍属P6，未在本任务执行；本次范围无剩余实现项。
