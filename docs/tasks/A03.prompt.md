# A03 原创装备图标：约 80 个基础图加程序变体，覆盖 400 个槽位

**执行者**：Codex（gpt-6-astra），使用 OpenAI 内置 imagegen
**前置阅读**：`AGENTS.md`；`docs/P3-PLAN.md`；`docs/tasks/A01.prompt.md` 及 `A01.report.md`（版权硬约束和工作方式完全沿用）；`docs/spec/13-art-requests.md` 中的装备图标一节；`docs/spec/04-items.md`；`data/items.json`（槽位、图标范围 `iconRangeInclusive`、名称池 `nameMappings`）。

## 版权硬约束

与 A01 相同：
- 禁止把原版 `icons.png` 或 `reverse/` 下的任何图片作为生成输入、参考、描摹或取色来源。
- 只能依据文字描述创作，例如装备类别、名称池里的名词（Sword、Helm、Amulet……）和 13 号规格中的分组建议。
- 每个基础图都要在 manifest 中记录来源和提示词。

## 范围与格式

- 原版共有 400 个图标槽位，即 `item.icon` 的取值 0–399，按 `data/items.json` 的范围分属各类装备：武器、头盔、盾、护甲、饰品，以及饰品下的 Amulet / Ring / Charm / Rune / Potion 名称池等。
- 按 13 号规格的 13 组分类，生成**约 80 个原创基础图**，每组数量按该组槽位数的比例分配。
- 用程序变体填满 400 个槽位，可用手法包括：
  - 换色（色相或材质：铜 / 铁 / 金 / 秘银 / 黑曜）；
  - 加纹饰或宝石；
  - 镜像；
  - 轻微的形状调整。
- 同组内相邻槽位要能分辨出来；同一个基础图的变体，在 49px 显示时仍要看得出差别。
- `art/items/items.png`：每格 **98 px**（原版 49 px 的 2 倍），按槽位编号行优先排列，20 列 × 20 行，总尺寸 1960×1960。图标背景透明，界面会自己画底框。
- `art/items/manifest.json`：每个槽位记录 slot、所属组、基础图 id、变体参数、来源 / 提示词（基础图的提示词，变体记录参数）。
- `art/items/src/`：基础图中间产物。
- `art/items/contact_sheet.png`：全部 400 个图标的总览。
- 生成脚本：`tools/art/items_build.py`、`tools/art/items_check.py`，必须能重跑。

## 自检

`items_check.py` 检查以下各项：
- 400 个槽位全部非空；
- 每个槽位的组与 `items.json` 的范围一致；
- 同组两两在 49px 下的平均差高于阈值，阈值自定并写入报告；
- 版权相似度筛查：方法同 A01，阈值 0.90。
