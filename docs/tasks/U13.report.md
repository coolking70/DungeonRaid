## 规则证据

- `Game::MatchTile @0x2ac40`：非Easy下进入特殊敌人正常奖励结算时，`game+0x14da0`减1，之后判断<1；冲刺由`RandI(0,100,0)<50`决定是否减1，因此每次50/101，不能将计数误称为保证掉落的精确击杀数。
- 同一函数检查`+0x14da4<3`与职业资格：当前非冒险者职业未满10级，或仍有未解锁职业。生成时重抽`RandI(20,30,0)`，无需等待领取。
- `InitNewGame @0x2d7a4`清零单局已生成数，保留间隔计数；Java `PREFS_TROPHY`跨局持久化。对应现有引擎`specialRewards`、`prepareNewRun`和`GameSession.save`。
