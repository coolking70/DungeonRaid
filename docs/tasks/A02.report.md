# A02 原创界面美术交付报告

完成日期：2026-10-15。任务范围内的图集、来源清单、中间产物、预览、构建与检查脚本均已交付；最终检查通过。

## 交付与风格

- `art/ui/ui.png`：2048×2048 RGBA，严格 2 倍像素，140 个无重叠图块，图块间保留 2px 空隙。
- `art/ui/manifest.json`：140 个实际图块和 182 个逻辑绑定（90 个语义图标＋92 个界面元素）。保留规格 id、已知逻辑尺寸、图集矩形、九宫格边距、状态、来源及提示词。
- 90 个语义图标：职业 10、种族 10、优点 10、缺点 10、技能 42、属性 8。Shock/Awe 分别为 SkillType.40/.41，没有把 COUNT 哨兵画成技能。
- HUD：经验紫／金币金／强化蓝三色填充及槽、生命液体与瓶身独立层、金币列、护甲、技能框充能／可用／禁用状态、菜单／统计、毒／燃烧／冰冻。
- 通用件：按钮三态、面板、折叠菜单选项底、标签页、滚动条、锁、勾、返回／翻页、选择框、死亡叉、光斑、粒子、护盾左右片、提示尖角；主菜单背景为 640×960。
- `src/base/` 保留 112 张逻辑尺寸中间图；`src/*.png` 保留 140 张最终双倍图；`sources.json` 和 `src/records/` 保存完整生成与处理记录。
- `preview.png` 是三个 320×480 逻辑画面并排的示意；`contact_sheet.png` 覆盖全部图块及 90 个图标的 32px 样本；`states_preview.png` 检查状态和九宫格拉伸。
- `tools/art/ui_build.py`、`tools/art/ui_check.py` 可重跑；接入字段、分层和重建说明见 `art/ui/README.md`。

采用暗黑奇幻像素风：炭黑轮廓、青铜边框、蓝灰石板、少量亮色魔法和金属高光。图标用不同轮廓、方向和主色区分，界面中部保持安静以容纳字体。普通素材量化至 24 色，背景 64 色，保留透明度，最终按最近邻放大。所有标题、按钮字和数值只出现在脚本绘制的预览中，不烘焙进图集。图集中没有游戏商标或开发商字样。

## 未决与已知不足

- 原生 Name/Class/Score/GameOver/Unlock 等复合容器及部分文字布局仍按 10／13 号规格列为未决；交付可九宫格拉伸的底板，不猜最终切图。任务限制不允许改规格文档，本报告记录继承的未决事项。
- 57 个绑定没有可用的固定原版图形 UV，或属于字体、代码、外部棋盘／动态图标；明确列入 `notApplicable`。新增效果和状态也没有独立原版对应片，未把它们冒充已完成逐片相似度比较。
- 32px MAE 用来排除重复近似，不能证明玩家能仅凭图像理解所有语义；24px 优缺点尤其仍需要界面名称或提示说明。
- 护盾片、粒子和状态图标提供静态素材种子；原生未解动画周期不在本卡中补造。生命与资源裁切、状态切换、字体和未知布局由后续 UI 接入实现。
- 三屏预览用于风格验收，没有实现运行时 UI 或将示意布局认定为原版精确布局。预览棋盘只读复用 A01 原创图块。
- 普通重建依赖 Python 3、Pillow、numpy；重新导入原始大图的 `--prepare` 还需要记录中的本机生成缓存。字节一致性是在当前依赖环境下验证的。
