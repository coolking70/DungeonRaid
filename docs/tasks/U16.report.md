# U16 — 中文冒险者显示排查与保留存档的缓存刷新

## 请求与结果

用户反馈：Android Firefox 中文新游戏页的冒险者按钮空白，英文正常且普通刷新无效。排查期间用户要求设置增加「清除缓存（保留存档）」功能。

已实现该入口、下载进度、失败重试和保存失败保护。当前对局、职业/成就/高分、奖杯计数、帮助状态及设置保留。实现和验证已完成，本次提交包含功能、测试、字体及文档。

## 排查证据

- `ui/front-screens.ts` 的 `Name.render` 对职业 0 使用与其他职业相同的动态标签路径；`data/i18n/zh.json` 的 `class.0.name` 为「冒险者」，没有空翻译。
- `ui/native-font.ts` 对中文正确回退到 Fusion Pixel；修改前字体子集已有「职业: 冒险者」全部字形，检查 glyph outlines 和 advance 均非空；这组文字以 12px 测量宽度为 70px，按钮 205px 宽，不是常规溢出。
- Chromium 桌面与手机尺寸、中英双语下逐一选择 10 个职业，实际文字区域都有可见像素；桌面 Firefox 158.0 的中文冒险者也正常。截图见 `U16.shots/mobile-zh-adventurer.png` 和 `firefox-adventurer.png`。
- 未确认 Android Firefox 空白的根因。没有证据可将问题归因于缓存，也没有对原本正常的职业名称或字体回退增加猜测性补丁。

## 实现

- `ui/resource-refresh.ts`：先刷新带时间戳的页面，再清除当前应用目录范围的 CacheStorage 条目，以 `cache:'reload'` 下载已加载的脚本、样式、字体、图片等资源。最多 4 路并发，每请求 15 秒超时，消费完整响应体后导航。
- 旧哈希资源 404/410 可继续更新，新页面加载新哈希；其他网络错误停留原页面。URL 的主题等参数保留。只刷新同源应用目录，不清空整个共享缓存桶，也不访问/删除 localStorage 或 IndexedDB。
- 设置入口先调用现有保存逻辑，保存失败则取消刷新。执行期间禁用返回/重试；失败后可重试或返回。原「清除档案」的双重确认仍保留。
- 8 条中英提示放入 `ui/help-copy.json`，中文字体新增「检源络网资」5 字；子集覆盖 1704/1704 字符，51436 字节。新增字与冒险者原有文字空白无关。
- 未修改规则引擎、存档格式、原版资源或 `reverse/`。该入口是用户要求的 Web 功能，无对应原版函数语义，不添加原版规则推断。

- `npm run build:ui` 成功；Vite 仍提示 app 分块超过 500kB（约 553kB / gzip 143kB），无构建错误。
- `tools/u16-browser.mjs` 在生产预览执行中英 × 桌面/触摸 4 组：成功刷新、刷新时输入锁定、断网后重试、保存失败不刷新、CacheStorage 范围、全部 localStorage 值逐字一致、继续棋盘后箭等格子状态保留。测试档案含游侠 3 级、7 局/91 击杀、成就进度 50%、距下个奖杯 17 次及已掉落计数 2；这些数据连同棋盘逐字保留。各组 10 职业标签有实际文字像素。未捕获运行时 pageerror；断网用例主动产生网络失败。

## 限制与后续

网页没有权限清空浏览器全局 HTTP 缓存；功能实际刷新本游戏资源，不删除其他站点数据。项目没有 Service Worker，不增加全站注销逻辑。网络/源站如果仍返回旧内容，该入口无法改变源站版本。

手机尺寸模拟和桌面 Firefox 不能代替 Android 真机。发布后需用户在手机上使用新入口，再确认中文冒险者是否恢复；若仍空白，继续对照设备/Android/Firefox 版本定位。用户尚未提供这些环境信息。
