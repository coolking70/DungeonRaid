# U04 局内界面：原版布局 HUD、全部局内动画与音效、折叠菜单、素材 / 文本 / 音频接入

**阶段**：P3。本卡先于 U03 执行，并负责把全部素材接入框架。
**执行者**：Codex（gpt-6-astra）。可以使用 `develop-web-game` 技能截图自检。
**前置阅读**：
- `AGENTS.md`、`docs/P3-PLAN.md`；
- `docs/spec/10-ui-screens.md`、`11-animation.md`、`12-audio.md`、`13-art-requests.md`；
- `docs/tasks/U02.report.md`：框架的 API 和扩展方式；
- `A01`、`A02`、`A03`、`S01`、`L01` 各卡的报告（素材、清单与接入说明）；
- `data/ui-layout.json`、`data/sounds.json`。

## 目标

做完本卡后，**局内**画面应当是一个完整的原版风格游戏：
- 布局、动画、音效都按 10–12 号规格还原；
- 美术使用原创图集；
- 文本默认中文，可以切换英文；
- 公开构建可以直接上线。

## 要做的事

### 1. 素材接入（框架层，本卡独占）

- 图集加载器接入以下三套素材，并处理 9-slice 绘制和状态变体（按下、禁用、锁定、选中）：
  - `art/ui/ui.png` 及其 manifest（2 倍分辨率；元素到资源的绑定见 manifest 的 `elements`）；
  - `art/items/items.png` 及其 manifest（每格 98 像素，400 个槽位）；
  - 原有的 `art/tiles.png`。
- 字体：加载 `fonts/fusion-pixel-12-subset.woff2`，按像素字体的要求做整数缩放、关闭平滑。
- i18n：接入 `data/i18n/zh.json` 和 `data/i18n/en.json`，默认中文，设置中可切换。语言切换的入口放到 U03 的设置屏幕，本卡先保证 `t()` 全面生效。
  - **装备名称**要按 L01 定义的中文拼接规则组装（前缀 + 名词），不要直接显示英文。
- 音频：接入 `src/audio/player.ts`。按 12 号规格的触发表，把引擎事件映射到音效 id 和变体：
  - 变体由 COSMETIC 选定的，按规格取值；规格允许 UI 自定的，用 UI 自己的种子。
  - 每个音效都要在有依据的分支上触发，**不能按事件名无条件发声**。
  - 浏览器要求先有用户手势才能播放音频，需要处理 AudioContext 的解锁。
- **运行时数据瘦身**：现在的 app 包有 1.79MB，原因是整份引入了带出处字段的 `catalog.json` 和 `ui-layout.json`。改为构建时（脚本放在 `tools/`）生成只含运行所需字段的精简 JSON，再由界面引入。目标是 gzip 后的 JS 总量降到原来的一半以下，把前后数据写进报告。

### 2. 局内 HUD 与棋盘（按 10 号规格）

- 棋盘：位置和尺寸、连线的绘制（线宽、颜色、端点、转角）、选中效果、调暗效果，以及拖线时实时显示「可击杀」预览（继承调试台已有的能力）。
- 顶部区域：
  - 4 个技能栏，含充能显示，以及可施放、充能中、禁用三种状态；
  - 「菜单」「属性」两个按钮。
- 底部 HUD：
  - 金币按列叠放（`UpdateGoldBar` 的 20 枚一列规则）；
  - 经验条、强化条；
  - 护甲数值与护甲图标；
  - 生命瓶的液面；
  - 毒、燃烧等状态图标；
  - 攻击和武器数值。
- 提示框（Tooltip）：长按或点击格子、技能、装备时显示，布局算法和边界按规格。
- 游戏菜单（「菜单」按钮）：7 个按钮，位置和顺序按规格（包括 Clock、Dimming、Smooth 等设置项）；其中帮助、退出到主菜单两项要真正可用。
- 属性面板（「属性」按钮）：显示当前属性和装备，装备图标取自 A03。

### 3. 折叠菜单（升级 / 商店 / 强化）

- 0.3 秒水平滑入。选项的坐标和命中区域按规格。
- 显示内容：
  - 技能候选：图标、名称、等级、冷却、描述；
  - 属性奖励：图标、加成；
  - 商店装备：A03 图标、中文名、属性列表，并与当前装备对比；
  - 卷轴：附带技能。
- 选择和确认的音效按规格。
- 标题文字原版是烘焙在图片上的（LEVEL UP! / Item Shop! / Upgrade!），现在改用字体渲染，加描边或发光。

### 4. 全部局内动画（按 11 号规格）

- 下落与补充；
- token 飞向资源条（`Token::Process` 的积分规则）；
- 资源影子；
- 伤害和数值飘字（`SimpleLabel` 各类型）；
- 闪光；
- 粒子（碎裂、火花、爆炸）；
- 护盾碎裂；
- 低血心跳；
- 调暗；
- 敌人能力的提示（冰冻、燃烧、偷金等的视觉反馈）；
- 奖杯与链的特殊格；
- 局终的展示序列，包括死亡、Sprint 胜利和 Pretzel 评级。

时间线约束：显示可以延后，但**不得改变规则的结算顺序**（见 U02 的规则快照与显示快照设计）。引擎已消费的 COSMETIC 结果，如果需要用于显示，按「只增不改」原则暴露并补测试；其余视觉扰动使用 UI 的独立种子，并标注为近似。
