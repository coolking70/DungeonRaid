# U14 — 原版格子强化与变体显示报告

## 发现与修改

- 原版箭替换整格贴图；魔剑对整格做蓝紫颜色调制。当前UI只加`>`和`+`，因此用户报告属实。
- 同类缺失还有法力、酸液、爆炸药水、破损剑盾。分别接回蓝药瓶、绿骷髅药瓶、带叉红药瓶、断剑、裂盾专用UV，去掉占位符/破损半透明替代。
- 原版持续增幅用技能槽蓝紫高亮表示，当前UI错误使用禁用框。现恢复蓝紫状态提示并加“生效/Active”可读标签，回合结束后恢复冷却显示；没有把普通增幅误画成魔剑。
- 按用户授权，复制原版棋盘图集并作为普通游戏界面默认；菜单/装备保持现有图集。`?art=redrawn`可对照此前重绘棋盘，A01缺少的变体从原版格位兜底。原版资源不是原创素材，来源/hash单独记录。
- `reverse/`、原APK、纯规则引擎、存档格式均未修改。

## 原版证据

- `Tile::MakeArrow @0x64294`：UV(565,459)到(618,512)，完整53px箭格；`Game::CreateArrows @0x2a108`遍历非魔剑/非箭的剑并替换，含破损剑。
- `Tile::MakeMagicSword @0x62db8`：RGB(150,150,255)，保留UV；已破损的剑保留断剑形状。
- `MakeManaPotion @0x642dc`、`MakeAcidPotion @0x64334`、`MakeExplosivePotion @0x6438c`：原appearance列，y=513/566/619。
- `MakeBroken @0x64a80`：断剑(424,778)、裂盾(424,725)。`Tile::Render @0x643e4`渲染Quad。
- `Skill::Activate @0x60210`技能16–19设置持续效果；`Interface::UpdateSkills @0x49544`与`Process @0x49988`维护蓝紫active高亮。Web使用静态蓝紫框与文字，没有实现原版约0.2秒的高亮染色插值。
- 原版贴图SHA-256 `4fc14a9d6f88a2580c7162759e8befc2eafcfa524f709f3329ef4a3f8b65ddc8`，与只读来源逐字节相同。
